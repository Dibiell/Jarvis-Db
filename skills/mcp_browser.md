# MCP: Browser & Automation

Controle total de navegação web e automação de tarefas no browser.

## Capacidades:
- **Interação Completa**: Clicar, digitar, scroll e extrair dados de qualquer site.
- **Visual Mapping**: Entender a estrutura visual do site para navegação inteligente.
- **Task Automation**: Preenchimento de formulários, extração de relatórios e monitoramento de sites.

## Implementação:
Utiliza o `browser_agent.py` como driver de execução e o protocolo MCP para interfacear com o Jarvis.
