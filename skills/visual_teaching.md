# Visual Teaching Skill
@visual_teaching

Este protocolo permite que o Jarvis aprenda novas habilidades observando a tela do usuário através de capturas periódicas.

## Como usar
Quando o usuário disser algo como "Quero te ensinar algo pela tela" ou "Vou te mostrar como faz", ative o modo de ensino visual. 
O sistema irá capturar screenshots a cada 3-4 segundos. No final, o Jarvis analisará a sequência para extrair a lógica e identificar anomalias.

## Capacidades
- Reconhecimento de fluxo de login.
- Identificação de navegação em ferramentas como NotebookLM e Google.
- Detecção de anomalias (erros visual, lentidão, comportamentos inesperados).
- Geração de lógica técnica para automação posterior.

## Instruções para o Jarvis
Sempre que sentir que uma tarefa requer demonstração visual para ser aprendida, sugira o uso deste protocolo.
