# MCP: 21st Dev Magic

Conector para o ecossistema 21st.dev de componentes e ferramentas frontend.

## Capacidades:
- **Magic Browser**: Um navegador especializado que pode "ver" componentes e estilos no 21st.dev.
- **Visual Search**: Buscar por layouts e componentes baseados em referências visuais ou descrições.
- **Component Import**: Importação direta de snippets de código validados para o projeto.

## Uso:
Ativar quando o Gabriel solicitar "Criar uma UI baseada em X" ou "Procurar um componente de Y".
