# Skill: Usage Monitor

Monitoramento em tempo real de tokens, custos e limites de API.

## Métricas:
- **Token Burn Rate**: Velocidade de consumo na sessão atual.
- **Estimativa de Custo**: Valor acumulado baseado nos preços das APIs (Anthropic, Groq, etc.).
- **Projeção de Contexto**: Avisar o usuário quando a janela de contexto estiver próxima do limite.

## Alerta:
O Jarvis deve notificar o Gabriel se o consumo atingir um patamar crítico pré-definido.
