# Skill: aiox-core (Syncra AIOS)

O núcleo de orquestração assíncrona para agentes full-stack.

## Capacidades:
- **Orquestração de Agentes**: Coordena múltiplos sub-agentes para tarefas complexas.
- **Contextual Planning**: Planejamento de desenvolvimento baseado no contexto global do projeto.
- **Async Execution**: Garante que tarefas de longa duração não bloqueiem a interação.

## Implementação:
Utilizado pelo `jarvis.py` para gerenciar a malha agêntica e o fluxo de dados entre core, cérebro e skills.
