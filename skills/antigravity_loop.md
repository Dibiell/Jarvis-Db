# Skill: Ralph Loop (Antigravity for Loop)

O ciclo de desenvolvimento autônomo infinito para conclusão de tarefas.

## O Fluxo:
1.  **Análise**: Entender os requisitos e o estado atual.
2.  **Ação**: Realizar as alterações necessárias (Código/Configs).
3.  **Verificação**: Executar testes e validar o comportamento.
4.  **Feedback Loop**: Se falhar, retornar ao passo 1 com os novos dados do erro.

## Condição de Parada:
O loop encerra apenas quando o critério de sucesso é atingido ou o limite de iterações configurado é alcançado.
