# Skill: n8n & External Automation

Esta skill conecta o JARVIS ao seu servidor **n8n**.

## Capacidades:
- **Trigger de Workflows**: Iniciar fluxos de automação complexos (Envio de e-mails, postagens em redes sociais, processos de CRM).
- **Webhooks**: Receber notificações do n8n e avisar o usuário.
- **Ponte de APIs**: Usar o n8n como intermediário para qualquer API que exija autenticação complexa.

## MCP Connector: `n8n-mcp`
Comunicar com a API do n8n para listar e executar fluxos ativos.
