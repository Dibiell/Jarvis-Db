# Skill: UI/UX Pro Max

Capacidades avançadas de design e implementação de interface premium.

## Capacidades:
- **Aesthetics Intelligence**: Sugestões de design baseadas em tendências modernas (Glassmorphism, Neon).
- **Component Discovery**: Identificação de componentes UI ideais para cada funcionalidade.
- **Design Systems**: Criação e manutenção de tokens de design consistentes.

## Regra de Ouro:
"Se não parecer premium, não está pronto." Utilize animações suaves e micro-interações em todas as respostas de GUI.
