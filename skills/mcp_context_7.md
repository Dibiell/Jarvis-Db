# MCP: Context 7

Sistema de injeção dinâmica de documentação e contexto técnico.

## Funcionalidades:
- **Doc Injection**: Injeta documentação atualizada de bibliotecas diretamente no prompt (evitando alucinações de APIs).
- **Version Control**: Garante que o Jarvis use a documentação da versão exata instalada no projeto.
- **Code Examples**: Fornece exemplos de uso real extraídos de repositórios confiáveis.

## Fluxo:
O `Context 7` age como um filtro mental, validando as sugestões de código contra documentações oficiais em tempo real.
