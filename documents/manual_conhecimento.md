# J.A.R.V.I.S. Manual de Conhecimento Local

Este é um arquivo de teste para o sistema de RAG (Retrieval-Augmented Generation) do Jarvis.

O Jarvis agora possui uma "Mina de Ouro" de funcionalidades inspiradas em projetos open-source do GitHub:
1. **Local RAG**: Permite que o Jarvis leia arquivos PDF, DOCX, TXT e MD diretamente da pasta 'documents'.
2. **Conselho de Agentes**: Uma orquestração multi-agente avançada baseada no ChatDev.
3. **Privacidade Total**: O processamento de documentos locais é feito 100% offline usando ChromaDB e modelos de embedding leves.

Para que o Jarvis saiba mais sobre você, adicione seus manuais, códigos ou livros nesta pasta e peça para ele "indexar documentos locais".
